# Pacote de Especialização Reutilizável

Competência operacional pra qualquer próximo dashboard de vendas/funil (não só esse projeto):

## Checklist de construção de funil
- [ ] Definir os estágios reais (não inventados) — confirmar cada um existe na fonte de dados
- [ ] Cada estágio mostra: nome, número absoluto, % de conversão pro próximo
- [ ] Visual: barras horizontais empilhadas, largura proporcional
- [ ] Destacar visualmente o maior ponto de queda (onde mais gente cai)

## Checklist de legibilidade pra tela grande
- [ ] Medir (ou estimar) a distância real de visualização da sala
- [ ] Aplicar fórmula: altura mínima do texto = distância(pés) × 0.01–0.014
- [ ] Revisar todo texto em CAIXA ALTA — trocar por minúsculas/title case exceto 1-2 destaques

## Checklist "isso é profissional de verdade ou só bonito?"
- [ ] Cada elemento na tela muda a decisão de alguém hoje?
- [ ] Cor tem função (estado/risco) ou é só estética?
- [ ] Dá pra remover sem perder informação? Se sim, remover.

## Checklist antes de prometer uma métrica nova
- [ ] Confirmar que o dado existe na fonte real (consulta direta, não suposição)
- [ ] Se não existir: comunicar isso ao usuário ANTES de construir a UI pra ela
